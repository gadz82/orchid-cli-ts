# @orchid-ai/orchid-cli

Commander.js CLI tool for the Orchid multi-agent AI framework — TypeScript port of `orchid-cli`.

## Install

```bash
npm install -g @orchid-ai/orchid-cli
```

## Usage

```bash
orchid chat send "Hello" --config path/to/orchid.yml
orchid chat interactive --config path/to/orchid.yml
orchid config validate path/to/agents.yaml
```
